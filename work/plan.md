# แผนแปล Tensura Neo Otherworld

ผู้ใช้อนุมัติเริ่มงานจากข้อเสนอในแชทแล้ว เป้าหมายรวมยังเป็นการแปลม็อด ไม่ใช่เฉพาะ batch แรก

## ระยะเริ่มต้น
- Instance: Tensura Neo Otherworld 1.1.3b2 / Minecraft 1.21.1 NeoForge
- เริ่มคำอธิบาย Tensura หลัก 723 รายการ จากนั้นขยายส่วนเสริม เควสต์ คู่มือ อุปกรณ์ และเมนูตามลำดับ
- แปล batch ละ 30 รายการ ตรวจทุก batch ก่อนดำเนินต่อ
- คงชื่อเฉพาะ/IDs/คำสั่ง/placeholder; สกิลที่ยังไม่มีศัพท์ตกลงคงอังกฤษไว้ก่อน
- ค่าเริ่มต้นที่เลือกสำหรับชุดตรวจ: ภาษาไทย th_th เท่านั้น ไม่เขียนทับ en_us; ไม่แนบฟอนต์หรือ JAR; ไม่มีชุด server
- ยังไม่ install ลง instance และไม่ commit/push
- Prominence เป็นแหล่งอ้างอิง ไม่คัดลอกคำแปลข้ามเวอร์ชันโดยไม่ตรวจ

## ข้อจำกัดที่ต้องตรวจต่อ
- 55 บทเควสต์ใช้ quests/lang/*.snbt เครื่องมือปัจจุบัน build ไม่รองรับ
- มี ftbqlang อยู่แล้ว ไม่ติดตั้ง FTBQuestTransl จากคำเตือนทั่วไปของเครื่องมือ
- KubeJS ต้องสำรวจเพิ่มเติม
- scan พบ 66 keys ซ้ำระหว่าง JAR ต้องตรวจลำดับ override ก่อนขยายงาน
- source.json เป็นข้อความที่ตัวกรองเลือก ไม่ใช่ข้อความทั้งหมดในม็อด
